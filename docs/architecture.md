# 项目架构说明

## 概述

`cjp-cli-dev` 是一个基于 Lerna 的 monorepo 前端工程化脚手架工具，采用多包管理架构，提供项目初始化、云构建发布、代码规范、Git 工作流等一站式开发支持。

当前版本：**1.7.5** | Node.js >= 16.0.0（推荐 16.20.2） | npm >= 8.19.4

## 架构总览

```
cjp-cli-dev/
├── core/                    # 脚手架核心
│   ├── cli/                 # CLI 入口，命令注册与解析

├── commands/                # 命令实现层
│   ├── init/                # 项目/组件初始化
│   ├── add/                 # 添加代码模板
│   ├── publish/             # 云构建与发布
│   ├── rollback/            # 版本回滚
│   ├── release/             # 版本升级与 CHANGELOG 生成
│   ├── gitflow/             # Git Flow 分支模型初始化
│   ├── husky/               # Git Hooks 配置
│   ├── codelint/            # 代码规范校验
│   ├── commitlint/          # 提交规范校验
│   ├── server/              # 静态资源托管服务

├── models/                  # 功能模型层
│   ├── command/             # 命令基类（所有命令的父类）
│   ├── package/             # NPM 包生命周期管理
│   ├── git/                 # Git 自动化操作
│   └── cloudbuild/          # 云构建通信
├── utils/                   # 工具层
│   ├── log/                 # 终端日志（基于 npmlog）
│   ├── format-path/         # 跨平台路径兼容
│   ├── get-npm-info/        # NPM Registry API 交互
│   ├── request/             # HTTP 请求封装

│   └── install-deps.js      # 子包依赖安装与全局软链脚本
├── lerna.json               # Lerna 多包管理配置
└── package.json             # 根 package.json
```

## 分层架构

项目采用清晰的四层架构设计：

```
┌─────────────────────────────────────────────────────┐
│                    用户终端输入                        │
│                 cjp-cli-dev <command>                │
└────────────────────────┬────────────────────────────┘
                         │
┌────────────────────────▼────────────────────────────┐
│                  Core 层（核心）                      │
│  cli: 命令注册、参数解析、环境检查                      │
│  exec: 动态加载命令包、子进程执行                       │
└────────────────────────┬────────────────────────────┘
                         │
┌────────────────────────▼────────────────────────────┐
│               Commands 层（命令实现）                  │
│  init / publish / add / release / husky / ...       │
│  所有命令均继承 models/command 基类                    │
└────────────────────────┬────────────────────────────┘
                         │
┌────────────────────────▼────────────────────────────┐
│                Models 层（功能模型）                   │
│  command: 命令基类，生命周期管理                       │
│  package: NPM 包下载/更新/缓存                       │
│  git: Git 自动化操作                                 │
│  cloudbuild: 云构建 Socket 通信                      │
└────────────────────────┬────────────────────────────┘
                         │
┌────────────────────────▼────────────────────────────┐
│                 Utils 层（工具）                      │
│  log / format-path / get-npm-info / request / utils │
└─────────────────────────────────────────────────────┘
```

## 核心设计思想

### 1. 命令动态加载机制

脚手架不直接引用命令实现代码，而是通过 `core/exec` 模块维护一张**命令 -> NPM 包名映射表**，在运行时动态下载/缓存命令包并在**子进程**中执行，实现了：

- 命令按需加载，减少初始启动开销
- 命令独立更新，无需升级整个脚手架
- 子进程隔离，命令崩溃不影响主进程

### 2. 命令继承体系

所有命令包必须继承 `models/command` 基类，基类提供统一的生命周期：

```
constructor → checkNodeVersion → initArgs → init（子类实现） → exec（子类实现）
```

子类必须实现 `init()` 和 `exec()` 方法，否则将抛出错误。

### 3. 包管理模型

`models/package` 封装了 NPM 包的完整生命周期管理，包括：
- 包的下载与安装（基于 npminstall）
- 版本检查与自动更新
- 本地缓存路径管理
- 入口文件路径解析

### 4. 多包管理

基于 Lerna v6.6.2 管理四个包目录（`core/*`, `models/*`, `commands/*`, `utils/*`），所有子包以 `@cjp-cli-dev/` 为 npm scope，使用 `file:` 协议引用内部依赖。

## 技术栈

| 类别 | 技术 |
|------|------|
| 多包管理 | Lerna 6.6.2 |
| 命令解析 | Commander.js |
| 用户交互 | Inquirer.js |
| 模板渲染 | EJS |
| Git 操作 | simple-git |
| 日志系统 | npmlog（定制） |
| HTTP 请求 | Axios |
| 云构建通信 | Socket.io Client |
| 静态服务 | Express |
| 文件操作 | fs-extra, glob |
| 进程管理 | cross-spawn |
